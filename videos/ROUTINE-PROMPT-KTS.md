Routine cloud chỉ có prompt ngắn trỏ tới file này. Sửa quy trình = sửa file này (không cần cập nhật routine).

  - videos/BRAND-SYSTEM-BOT-BAN-HANG.md
  - videos/PRODUCTION-WORKFLOW-BOT-BAN-HANG.md
  - videos/CONSTRUCTION-STYLES-BOT-BAN-HANG.md

EOF), TUYỆT ĐỐI KHÔNG gõ thẳng text tiếng Việt vào curl -d "..." — dễ lệch encoding qua Git Bash, server nhận text méo nên tổng hợp giọng sai/vô nghĩa dù HTTP vẫn trả status:1/200 bình thường (không có lỗi rõ ràng để phát hiện). Gọi bằng curl --data-binary @lineN.json --max-time 90 (phản hồi mất 15-25 giây, KHÔNG phải lỗi). Thành công trả {"status":1,"result":{"audio_link":"https://vbee.vn/s/...",...}} — audio_link CHỈ HIỆU LỰC ~3 PHÚT, tải ngay (curl -sL -o lineN.mp3 "<audio_link>"). status:0 → đọc error_message, DỪNG và báo rõ.
